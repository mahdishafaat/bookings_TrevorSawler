# Bookings and Reservations

_Note: This repository is a personal learning space. I am building this project while following Trevor Sawler's Go web development course. It is not intended to be a polished portfolio piece, but rather a sandbox for understanding the underlying mechanics and fundamentals of web architecture in Go._

This is the repository for my bookings and reservations project.

- Built in Go version 1.26.2
- Uses the [chi router](https://github.com/go-chi/chi/v5) for routing
- Uses [alex edwards SCS](https://github.com/alexedwards/scs/v2) for session management
- Uses [nosurf](https://github.com/justinas/nosurf) for CSRF protection
